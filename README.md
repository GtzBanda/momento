# Momento

## What is this?

Momento is a web app concept that turns digital tickets and event information into organized memories. The idea is to give users a simple way to save an experience, add a favorite photo, write a short story about the moment, and view it as a keepsake. The current version is an interactive prototype that demonstrates the main flow of creating and saving a memory.

## Why does it exist?

I created Momento because tickets and event information are often easy to lose or forget after an experience is over. The goal is to give people a simple and more personal way to preserve those moments instead of just keeping a screenshot of a ticket. The project is designed for people who want to keep memories from concerts, sporting events, trips, movies, and other experiences in one place.

## What tools did I use?

- **React** - I used React to build the interactive parts of the Momento prototype and manage the different screens and user interactions.
- **JavaScript** - I used JavaScript to control the application logic, including the memory text, character counter, navigation, and photo upload functionality.
- **CSS** - I used CSS to create the layout, styling, responsive behavior, cards, buttons, and overall visual design.
- **Visual Studio Code** - I used VS Code as my code editor while building and testing the project.
- **GitHub** - I used GitHub to store and manage the project code.
- **GitHub Pages** - I used GitHub Pages to deploy the project so it can be accessed through a web browser.
- **ChatGPT** - I used ChatGPT as an AI assistant to help me work through coding problems, review my implementation, and make improvements to the project.
